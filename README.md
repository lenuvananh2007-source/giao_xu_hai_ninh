# Giáo xứ Hải Ninh

Mã nguồn website Giáo xứ Hải Ninh – Giáo phận Hải Phòng.

## Cấu trúc
- `index.html` – trang chủ
- `styles.css` – giao diện vàng cổ điển + xanh navy
- `app.js` – tương tác cơ bản

## Chạy
Mở `index.html` trực tiếp trên trình duyệt hoặc triển khai repository này trên Vercel.

## Định hướng phát triển
- Dữ liệu Giáo xứ: Giáo xứ Hải Ninh, Giáo họ Viên Chử
- Danh sách giáo dân và hồ sơ 360°
- Hộ gia đình
- Hội đoàn
- Các vị Mục tử qua từng thời kỳ
- Lịch phụng vụ
- Tin tức, thông báo và các module quản trị nội bộ
